Photos referenced by `photo=` in `../family.md` live here.

Any `.jpg`, `.jpeg`, `.png`, `.webp` or `.svg` works; square crops around 400×400
look best. The offline build inlines whatever is in this folder into the single
HTML file, so keep the files small — a few hundred KB each at most.

The three `.svg` files are placeholder portraits for the sample family. Delete
them once you have real photos.
